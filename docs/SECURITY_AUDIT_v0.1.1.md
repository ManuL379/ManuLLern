# ManuLLern v0.1.1 — Security & Integrity Audit

Date: 2026-09-23

## Проверено

- `app.js` и `sw.js` проходят синтаксическую проверку JavaScript.
- Все JSON/manifest-файлы корректно разбираются.
- В исполняемых файлах приложения нет внешних URL, сторонних JavaScript/CDN, аналитики или рекламных SDK.
- Service Worker перехватывает только GET-запросы того же origin.
- CSP ограничивает скрипты, стили, изображения, соединения, worker и manifest ресурсами самого приложения.
- Прогресс хранится только в `localStorage`; тексты ответов не записываются в прогресс.
- Импортированные уроки хранятся локально в IndexedDB.
- Импорт прогресса ограничен 1 МБ и очищается до ожидаемой структуры.
- Импорт пакета уроков ограничен 5 МБ и 100 уроками, проходит структурную проверку и не может заменить существующие уроки тем же ID.
- 10 стартовых уроков точно соответствуют диапазонам Anki #1–100: по 10 слов на урок.
- `deck_index_5000.json` содержит ровно 5000 последовательных позиций #1–5000.
- Вложенная Anki-колода содержит 5000 заметок и 11800 карточек.
- Проверены все 1800 контекстных карточек Anki на соответствие `пропуск + ответ = полная фраза`.
- Исправлены 8 контекстных карточек, где пропуск ранее приходился на часть слова/формы вместо полного ожидаемого элемента (включая `in`, `ein`, `zu`, `dies`, `all`, `kein`, `jede`, `welch`).
- Проверена целостность SQLite базы Anki после исправления (`PRAGMA integrity_check = ok`).

## Что нельзя гарантировать одной статической проверкой

- Нулевое количество языковых/стилистических ошибок во всех будущих 500 уроках или 25 000 примерах без отдельной редакторской проверки контента.
- Полную офлайн-приватность системного TTS и голосового ввода: это зависит от настроек Android/Brave/Gboard. Для максимальной приватности нужны офлайн-пакеты немецкого TTS/распознавания.
- Защиту от компрометации аккаунта хостинга. Для публичного размещения нужен 2FA и публикация релизов с SHA-256.

## Модель приватности

Сам ManuLLern не отправляет ответы пользователя на сервер и не содержит кода для таких отправок. При обычной работе сеть нужна только для первой загрузки/обновления статических файлов с выбранного хостинга. После кэширования основной интерфейс и стартовые уроки работают офлайн.
