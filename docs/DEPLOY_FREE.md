# Бесплатная публикация на Cloudflare Pages

ManuLLern — статическая PWA, поэтому платный сервер не нужен.

## Вариант без собственного домена

1. Создать бесплатный аккаунт Cloudflare.
2. Pages → Create project.
3. Загрузить содержимое этой папки как статический сайт (или подключить Git-репозиторий).
4. Build command: пусто.
5. Output directory: `/` (корень проекта).
6. После публикации Cloudflare выдаст бесплатный адрес вида `*.pages.dev`.
7. Открыть адрес в Brave → меню → «Добавить на главный экран» / «Установить приложение».

Платный домен не нужен.

## Важно

Не добавлять:
- Google Analytics;
- рекламные SDK;
- внешние скрипты;
- облачную AI-проверку;
- формы регистрации.

Это сохраняет фирменный принцип ManuLLern: **простота, приватность, результат**.
