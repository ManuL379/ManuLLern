# Security / Безопасность

1. Все основные ресурсы проекта — локальные статические файлы.
2. Нет стороннего JavaScript, CDN, аналитики или рекламных библиотек.
3. Service Worker кэширует только файлы того же origin и не проксирует сторонние запросы.
4. Импорт пакетов уроков требует `formatVersion: 1`, ограничен 5 МБ/100 уроками, проходит структурную проверку и не может молча заменить существующий урок.
5. Импорт прогресса ограничен 1 МБ и очищается до ожидаемых числовых полей.
6. В HTML задана Content Security Policy: только ресурсы того же origin, без внешних скриптов, object/embed и внешних соединений.
7. Service Worker перехватывает только same-origin GET и не подменяет JSON/изображения HTML-страницей при офлайн-сбое.
8. Прогресс можно экспортировать в JSON и хранить отдельно как резервную копию.
9. Перед публичным релизом рекомендуется:
   - включить 2FA на аккаунте хостинга/Git;
   - публиковать релизы с SHA-256;
   - использовать HTTPS;
   - хранить исходный архив первого релиза отдельно.
