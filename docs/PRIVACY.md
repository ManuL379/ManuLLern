# Privacy / Приватность

## Коротко

ManuLLern спроектирован как **local-first** приложение.

- Нет регистрации.
- Нет рекламных SDK.
- Нет аналитики.
- Нет облачной базы.
- Нет AI/API-проверки ответов.
- Ответы пользователя не отправляются на сервер.
- Текст введённых ответов не сохраняется в прогрессе.
- Прогресс хранится локально в браузере на устройстве.
- Импортированные пакеты уроков хранятся локально в IndexedDB.
- Экспорт прогресса создаётся только по явному нажатию пользователя.

## Сеть

Код приложения не делает запросов к сторонним сервисам. При первой загрузке PWA браузер получает статические файлы с хостинга. После кэширования основной курс работает офлайн.

TTS (озвучивание) и голосовой ввод — системные функции телефона/браузера. Их сетевое поведение определяется установленным TTS/клавиатурой Android, а не ManuLLern. Для максимально приватного режима используйте скачанные офлайн-пакеты немецкого языка.

## Что хранится

Локально:
- номер урока;
- число открытий;
- число завершений;
- число повторов;
- импортированные пакеты уроков.

Не хранится:
- текст свободных ответов;
- голосовые записи;
- email;
- имя;
- адрес;
- рекламный идентификатор.
