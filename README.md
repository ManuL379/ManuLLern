# ManuLLern

**RU:** ManuLLern — бесплатный и приватный помощник для изучения немецкого: аудирование, тексты, короткие модели построения фраз и диалоги. Работает офлайн после установки, без аккаунта и без отправки учебных данных.

**DE:** ManuLLern ist ein kostenloser und datenschutzfreundlicher Begleiter zum Deutschlernen: Hörverstehen, Texte, kurze Satzmuster und Dialoge. Nach der Installation offline nutzbar, ohne Konto und ohne Übertragung deiner Lerndaten.

## Главный принцип

Anki отвечает за запоминание слов. ManuLLern — за применение языка.

Курс синхронизирован с колодой **Deutsch 5000**:
- 10 новых слов Anki → 1 урок ManuLLern;
- целевой курс — 500 уроков / 5000 слов;
- старые слова постоянно возвращаются в следующих текстах;
- сложность растёт плавно;
- любой урок можно повторять сколько угодно.

## Что уже есть в v0.1.1

- PWA, устанавливаемая из Brave/Chromium на главный экран;
- работа офлайн после первой загрузки;
- первые 10 полноценных уроков (Anki #1–100);
- режим «сначала на слух»;
- перевод каждого предложения по нажатию;
- полный перевод по запросу;
- ручное TTS немецкого текста и диалогов;
- короткие модели построения предложений без длинных правил;
- локальная проверка ответа по 3 подготовленным естественным вариантам;
- отдельные подсказки по регистру, ä/ö/ü/ß и близким опечаткам;
- прогресс хранится локально;
- сами тексты ответов не сохраняются;
- экспорт/импорт прогресса;
- импорт новых локальных пакетов уроков с проверкой структуры, размера и без перезаписи уже существующих уроков;
- колода Anki включена в папку `downloads/`.

## Приватность

В коде приложения нет аналитики, рекламы, аккаунтов, AI/API и внешних сетевых запросов. Добавлена строгая Content Security Policy (CSP), а импортируемые файлы проходят локальную валидацию и ограничения размера. После установки основная работа идёт локально. Системный TTS/голосовой ввод зависят от настроек Android/браузера; для максимально офлайн-режима нужно скачать немецкие офлайн-пакеты на устройстве.
